# 小组演示

在已登录的工作台打开“小组演示”，上传 UTF-8 单文件 HTML（最大 16 MiB）。课件的样式、脚本和资源须内嵌，图片与音视频可使用 data URL。点击“播放”进入隔离播放器，可全屏。下载得到原 HTML，课前可保留离线副本。替换或删除前会弹出确认。

列表、上传、替换、删除、播放和下载都沿用登录鉴权。播放使用不授予同源权限的 iframe，内容响应自身也带 CSP sandbox 与资源限制，即使直接访问播放地址也处于隔离源。普通 HTML 课件可运行内联脚本。外部网络、嵌套框架、表单提交与父页访问均受到限制。

每个数据槽有独立 `presentations.sqlite`。班务 JSON 备份仍负责通知与任务。服务器快照命令为现有班务快照另写同名的 `.presentations.sqlite` 伴随文件，两份都应保留在同一目录。恢复命令会恢复该伴随库（如果存在），目标必须是新数据槽。旧快照仍可恢复班务，登录数据库独立管理。

示例课件见 [智慧水利与国防](../courseware/01-water-defense.html)。
